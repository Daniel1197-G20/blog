# Next.js Redux-Saga Blog

A production-quality blog application built with Next.js App Router, Redux Toolkit, Redux-Saga, and Tailwind CSS. This project serves as a comprehensive developer assignment showcasing scalable frontend architecture, robust state management, and clean code principles.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Redux Toolkit
- Redux-Saga
- Axios
- DummyJSON (API)

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Project Structure

```
├── app/          # Next.js App Router routes, layouts, and providers
├── components/   # Modular and reusable UI components (common, blog, auth)
├── hooks/        # Custom React hooks (e.g., useAuth, useLocalStorage)
├── lib/          # API client instance and service modules
├── public/       # Static assets (images, icons)
├── store/        # Redux Toolkit store, slices, sagas, and selectors
└── utils/        # Shared helper functions, constants, validators, and cache utilities
```
